# Week11 AIと考えたログ ## Part 1：AIと考えた1セッション ### テーマ Splideでスライダーを実装するときに使う`mount()`の意味についてAIに質問した。 ### 送った指示（良いプロンプトの型） 目的: Splideを使ったスライダーのコードを理解し、自分で説明できるようになる。 前提: HTML・CSS・JavaScriptを使ってポートフォリオサイトを作成しており、Splideで作品スライダーを実装している。以下のコードを使用している。 ```js const splide = new Splide("#portfolio-slider", { type: "loop", perPage: 2, autoplay: true, }); splide.mount(); ``` 見てほしい観点: `new Splide()`と`mount()`の役割の違い、特に`mount()`の意味を初心者にも分かるように説明してほしい。 制約: 難しい専門用語をできるだけ使わず、具体例を使って説明する。 出力形式: それぞれのコードの役割を分けて説明し、最後に簡単にまとめる。 ### 返ってきた出力（要約） AIから、`new Splide()`はSplideのスライダーを作成する処理で、`mount()`は作成したSplideを実際に動かすための処理だと説明された。 また、JavaScriptでは関数を実行するときに`()`を付けるため、`mount`ではなく`mount()`と書く必要があると説明された。 ### "なぜ"を聞いた記録 * 聞いたこと: `mount()`はなぜ`()`が必要なのかを質問した。 * 返ってきた説明（要約）: `mount`は関数そのものを指しているだけだが、`mount()`とすると、その関数を実行するという意味になる。JavaScriptでは、関数を実行するときに`()`を付ける。 * 聞く前は分からなかったが、聞いて分かったこと: `()`には「この関数を実行する」という意味があることが分かった。今まではコードに書いてあるものとして覚えていたが、`hello()`のような普通の関数でも同じ仕組みだと理解できた。 ### 出力の4分類 | 分類 | 内容 | 判断理由 | | ----- | ----------------------------------------- | ------------------------------------------- | | 採用する | `new Splide()`でスライダーを作成し、`mount()`で実際に動かす | 実際のコードの動作と一致しており、役割も理解できたため | | 保留する | Splideの細かい内部処理についての説明 | 今回の課題では必要以上に深く理解する必要がないため | | 採用しない | 自分のHTML構造とは異なるコード例 | そのまま使用すると自分のコードに合わないため | | 要確認 | Splideの`mount()`の内部で具体的にどのような処理が行われているか | 今回は関数を実行する役割までは理解できたが、内部の詳しい処理までは確認できていないため | --- ## Part 2：流された場面の振り返り Week10のFetchの課題で、AIから提示されたJavaScriptのコードを、各行の意味を十分に理解しないまま使ってしまったことがあった。動作したのでそのまま採用してしまったが、後からコードの意味を理解することが大切だと感じた。 --- ## Part 3：今後のAI利用方針 ### Week11で気づいたこと AIにコードを作ってもらうだけでは、自分がコードの意味を理解できていない場合があると分かった。特に「なぜこの書き方なのか」を聞くことで、コードの仕組みを理解しやすくなった。 ### 自分のAI利用ルール 1. AIからコードをもらったら、分からない部分を最低1つは「なぜ」と質問する。 2. AIのコードをそのまま使わず、自分のコードに必要かどうかを確認する。 3. 分からないクラス名や関数は、意味を確認してから採用する。
